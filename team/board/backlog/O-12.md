# O-12: CI-Flakes Linux/Windows beseitigen (apt-Timeouts, sccache-Start)

Meilenstein: bald (vor M1-09) · Agent: implementer · Herkunft: Runs 37893684864, 37936089214, 37941826083

## Fakten
- `apt-get install` im Linux-Build/RTSan-Job dauert bei langsamem Azure-Mirror > 20 min (Timeout, z. B. RTSan in Run
  37936089214: 13:20–13:40). Paketliste groß (ffmpeg, lame, xvfb, JUCE-Dev, clang).
- Windows Debug: `sccache: Timed out waiting for server startup` beim Konfigurieren (Run 37941826083, 1. Versuch).
- Re-Runs waren jeweils grün → reine Infrastruktur, aber jede zweite Code-Änderung braucht einen Re-Run.

## Auftrag
1. apt-Pakete cachen (z. B. `actions/cache` auf `/var/cache/apt/archives` oder eine gepflegte Cache-Action) und
   Paketliste ausdünnen (siehe O-01: nicht benötigte Pakete per Deinstallation prüfen).
2. sccache: Server vor dem Konfigurieren explizit starten (`sccache --start-server`) mit erhöhtem
   `SCCACHE_STARTUP_TIMEOUT`; bei Fehlschlag ohne sccache weiterbauen statt rot.
3. Nachweis: drei aufeinanderfolgende grüne Läufe auf `main` ohne Re-Run.
